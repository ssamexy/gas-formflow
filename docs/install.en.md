# GAS FormFlow Quick Installation

After a one-time setup, you can open your private FormFlow Web App from a phone or desktop browser.

Estimated first-time setup: about 10 minutes.

## Before you start

- Use the Google account that should own the generated Forms and Sheets.
- Create and deploy your own Apps Script project.
- Set Web App access to **Only myself**.
- Do not use a Web App URL supplied by a stranger or publish your private Web App URL.

## 1. Create a standalone Apps Script project

1. Open [Google Apps Script](https://script.google.com/).
2. Create a new project.
3. Rename it to `GAS FormFlow`.

This is a standalone project. It does not need to be bound to a Google Sheet.

## 2. Copy two files

### Code.gs

1. Open [dist/Code.gs](../dist/Code.gs).
2. Copy all content.
3. Open the default `Code.gs` in Apps Script.
4. Replace its content with the copied code.

### Index.html

1. Click the plus button next to Files in Apps Script.
2. Choose HTML.
3. Name the file `Index`.
4. Open [dist/Index.html](../dist/Index.html).
5. Copy all content into `Index.html`.
6. Save the project.

The filename must be `Index.html` with matching capitalization.

## 3. Authorize the project

1. Select `setup` from the function list.
2. Click Run.
3. Choose your Google account and complete authorization.
4. Confirm that the project name is the `GAS FormFlow` project you just created.

Google may show an unverified app screen because this is a private Apps Script project created in your own account. Verify the account, project name, and source before continuing.

See [Security, data, and permissions](../SECURITY.md) for the reason behind each permission.

## 4. Deploy a private Web App

1. Click Deploy.
2. Select New deployment.
3. Choose Web app.
4. Set Execute as to **Me**.
5. Set Who has access to **Only myself**.
6. Deploy and copy the Web App URL.

Required settings:

| Setting | Required value |
|---|---|
| Execute as | Me |
| Who has access | Only myself |

Do not select Anyone or Anyone with the link. A public deployment could let other people create Forms and Sheets under your account or consume your AI API quota.

## 5. Verify the installation

1. Open the Web App URL while signed in to the same Google account.
2. Load a built-in example.
3. Update the preview.
4. Confirm that the form preview appears.

You can complete this check without configuring an AI API Key. Google Drive resources are created only after you explicitly click Create form.

## Updating

1. Replace `Code.gs` and `Index.html` with the latest files from `dist/`.
2. Save and run `setup` again.
3. Open Deploy > Manage deployments.
4. Edit the existing deployment, select New version, and deploy.

Updating the existing deployment usually keeps the same Web App URL.

## Common questions

### The Web App says I do not have access

Sign in with the same Google account that deployed it.

### My code changed but the Web App did not

Saving code does not update a versioned Web App. Create a new deployment version under Manage deployments.

### Can I share the Web App URL with coworkers?

The beginner deployment is designed for one private administrator. Share the generated Google Form URL with respondents, not the FormFlow Web App URL.
